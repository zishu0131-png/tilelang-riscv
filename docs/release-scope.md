# 发布范围与限制

## 三仓职责

- 总仓 `tilelang-riscv`：研究架构、验证范围、复现导航和版本配套表。
- `numba2tilelang`：189 基线转换器源码、必要辅助、演示和旧诊断测试。
- `tilelang2rvv`：已有公开 RVV 消费器源码、示例、运行支持和测试。

独立仓库 README 相互链接并回到总仓。当前源码不在总仓重复存放；旧源码和原发布 manifest 仍保留在总仓历史提交 `3058b8046098b2ff64fab26ba23a0a5f4a40fe8a`，未改写历史。

## 有意不包含

内部交接及授权记录、外部采集语料、模型权重、私有设备或凭据配置、缓存、构建产物、历史候选快照，以及完整 VLM 实验材料。本次不是研究开发目录的全量镜像。

## 证据边界

- 转换器核心原字节来自189，辅助文件单列来源；不把新能力描述成任意输入支持。
- RVV 8件源码沿用已公开副本，不接管或修改其开发目录。
- 代码接受、文本生成、设备编译、数值正确、性能分别验证。
- CUDA threads 路径与可移植 tile 路径不同，不能声称所有上游输出都可在 RVV 执行。
- QEMU 单 hart 功能结果不是多核验证、真实芯片性能或 VCIX 验证。
- 独立仓库版本表仅固定来源组合，不是整链兼容性证明。

## 权利状态

沿用首次公开时未选择额外项目开源许可证的状态；不擅自授予 MIT/Apache 等许可。第三方依赖独立遵守其许可证。文件筛选和常见敏感模式检查不等于版权确权或全面安全审计。
